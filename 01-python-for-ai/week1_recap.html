Day 1

References & mutability

A Python variable is a label pointing to an object, not a box holding a value. This is why shared state causes bugs.

Remember

  • def f(x=[]) creates the list once, shared by every call. Use None as the default.
  • A list written in the class body is shared by all objects. Create it in __init__.
  • .copy() is shallow (nested data still shared); copy.deepcopy() copies everything.
  • Catch only the error you expect. A bare except: hides real bugs.

Code

def add_tag(tag, tags=None):
    if tags is None:
        tags = []              # fresh list on every call
    tags.append(tag)
    return tags

self.messages = []             # in __init__, never in the class body
new_config = copy.deepcopy(base)
new_list = items + [item]      # new list, original untouched

Pydantic: type hints that are enforced

A Pydantic model checks data when it is created, converts safe values ("3" becomes 3), and reports every error at once.

Remember

  • Literal[...] limits a field to fixed values; Field(ge=, le=, min_length=) adds limits.
  • Nested models are validated all the way down; errors point to the exact spot, like items.0.quantity.
  • A field with a default and limits: the default goes inside Field(default=3, ge=0, le=10).

Code

class Ticket(BaseModel):
    category: Literal["bug", "feature", "question"]
    priority: int = Field(ge=1, le=5)
    summary: str = Field(min_length=5)
    tags: list[str] = []

Ticket.model_validate_json(text)    # JSON string -> object
Ticket.model_validate(data)         # dict -> object
ticket.model_dump()                 # object -> dict
ticket.model_dump_json()            # object -> JSON string
Ticket.model_json_schema()          # the model describes itself

Day 4

Validators, nested models, tool schema

Rules beyond types, and feeding errors back to the LLM so it can retry.

Remember

  • @field_validator: clean, check, return. Inside it, raise ValueError(...); Pydantic wraps it.
  • Strings are immutable: value = value.strip(), not just value.strip().
  • Never compare money floats with ==. Use abs(a - b) > 0.01.
  • model_json_schema() becomes the tool definition you give the LLM.

Code

@field_validator("currency")
@classmethod
def clean(cls, value: str) -> str:
    value = value.strip().upper()                          # clean
    if len(value) != 3 or not value.isalpha():
        raise ValueError("currency must be 3 letters")     # check
    return value                                           # return

@model_validator(mode="after")
def check_total(self):
    if abs(sum(i.amount for i in self.items) - self.total) > 0.01:
        raise ValueError("total does not match the items")
    return self

".".join(str(part) for part in err["loc"])   # "items.0.quantity"

Day 5

httpx: calling APIs from Python

Postman in code. Every LLM call is an HTTP request.

Remember

  • httpx does not raise on 4xx/5xx. Call raise_for_status().
  • Two error families: HTTPStatusError (server answered with an error) and TransportError (no answer: timeout, connection).
  • Pass the client into your functions (dependency injection) so tests can use MockTransport instead of the network.
  • When "not found" is normal, check status_code == 404 before raise_for_status().
  • Always set a timeout.

Code

client = httpx.Client(base_url="https://api.example.com",
                      headers={"Authorization": f"Bearer {key}"},
                      timeout=10.0)
response = client.get("/users/1")
response.raise_for_status()
data = response.json()
client.post("/users", json={"name": "Asha"})

Day 6

Retries with backoff

Which failures to retry, how long to wait, and how to test it without really waiting.

Remember

  • Retry 429, 500, 502, 503, 504, 529 and timeouts. Never retry 400, 401, 403, 404, 422.
  • Wait 1s, 2s, 4s, 8s… capped. If the server sends Retry-After, use that instead.
  • Pass sleep in as a parameter so tests record the wait instead of waiting.
  • A bare raise inside except re-raises the same error. Use is None, not truthiness, when 0 is valid.

Code

if 200 <= status_code < 300: return "ok"
return min(base * 2 ** attempt, cap)       # backoff

for attempt in range(max_attempts):
    is_last_attempt = attempt == max_attempts - 1
    try:
        response = client.request(method, url, **kwargs)
    except httpx.TransportError:
        if is_last_attempt:
            raise
        sleep(backoff_delay(attempt))
        continue

Day 7

Async: waiting without being stuck

Run many slow calls at the same time. 10 requests take about the time of one.

Remember

  • An async def function does not run until you await it. Without await you get <coroutine object>.
  • Only the slow call (network, sleep) gets await. .json() and raise_for_status() don't.
  • asyncio.gather runs all together and returns results in input order.
  • Use asyncio.sleep, never time.sleep, inside async code.
  • If a result shows <coroutine> or <Future>, an await is missing.

Code

async def fetch_json(client, path):
    response = await client.get(path)     # the slow call: await
    response.raise_for_status()
    return response.json()

results = await asyncio.gather(*(fetch_json(client, p) for p in paths))
results = await asyncio.gather(*coros, return_exceptions=True)   # errors as values
result = await asyncio.wait_for(coro, timeout=5)                 # raises TimeoutError
asyncio.run(main())                                              # start the program

Day 8

Async at scale: limits and batches

Run many LLM calls, but only N at a time, so you stay under the API's rate limit.

Remember

  • gather starts everything; the semaphore is what limits how many run at once.
  • A task is a function that makes a coroutine: lambda: classify(text). Calling it gives a fresh coroutine each time.
  • Lambda-in-a-loop trap: use lambda t=text: ... so each one keeps its own value.
  • One bad item must not stop the batch: catch the expected errors and return None.

Code

semaphore = asyncio.Semaphore(limit)

async def run_one(task):
    async with semaphore:
        return await task()

return await asyncio.gather(*(run_one(t) for t in tasks))

tasks = [lambda t=text: one(t) for text in texts]

Day 9

Config & secrets

API keys never go in code or git. They live in environment variables or a git-ignored .env file.

Remember

  • An environment variable is always a string. os.environ.get("X") returns None if missing; os.environ["X"] crashes.
  • Commit .env.example (fake values). .env stays git-ignored.
  • In a Settings class you only declare fields; pydantic-settings fetches, converts and validates.
  • A field with no default is required. SecretStr hides the value when printed.
  • Priority: argument, then real env var, then .env file, then default.

Code

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    anthropic_api_key: SecretStr                         # required
    llm_model: str = "claude-sonnet-5"                   # default
    max_retries: int = Field(default=3, ge=0, le=10)     # default + limits

settings = Settings()
settings.anthropic_api_key.get_secret_value()            # reveal on purpose

Day 10

pytest fixtures

A fixture prepares what a test needs. A test asks for it by naming it as a parameter. (Only works in pytest.)

Remember

  • Each test gets a fresh copy, so tests can't affect each other.
  • A fixture can use another fixture (add it as a parameter). Shared fixtures live in conftest.py.
  • yield splits a fixture into setup and cleanup; cleanup runs even if the test fails.
  • Built-ins: tmp_path (temporary folder) and monkeypatch (temporary changes, undone automatically).

Code

@pytest.fixture
def store():
    return TicketStore()

@pytest.fixture
def loaded_store(store):          # uses the store fixture
    store.add(Ticket(1, "bug", "Login crash"))
    return store

def test_x(loaded_store, tmp_path, monkeypatch):
    monkeypatch.setenv("ANTHROPIC_API_KEY", "sk-test-123")

class Ticket:
    count = 0                       # class attribute: SHARED by all tickets

    def __init__(self, title):      # runs when you create an object
        self.title = title          # instance attribute: one per object
        Ticket.count += 1

    def __repr__(self):             # how the object prints
        return f"Ticket({self.title!r})"

    @property
    def short(self):                # use like an attribute: t.short
        return self.title[:5]

    @classmethod
    def from_text(cls, text):       # alternative constructor
        return cls(text.strip())

    @staticmethod
    def is_valid(title):            # plain function that lives inside the class
        return bool(title)

Comprehensions & generators

{n for n in range(10) if n % 2 == 0}       # set comprehension -> {0, 2, 4, 6, 8}
{w: len(w) for w in ["a", "bb"]}           # dict comprehension -> {'a': 1, 'bb': 2}
sum(n * n for n in range(5))               # generator expression (no list built) -> 30

def count_up(limit):
    n = 0
    while n < limit:
        yield n                            # pause here and hand back ONE value at a time
        n += 1
list(count_up(3))                          # -> [0, 1, 2]
next(iter([10, 20]))                       # take the first value of an iterator -> 10

Decorators & context managers

import functools, time
from contextlib import contextmanager

def timed(func):                           # a decorator: takes a function, returns a new one
    @functools.wraps(func)                 # keep the original name and docstring
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.3f}s")
        return result
    return wrapper

@timed                                     # same as: slow = timed(slow)
def slow():
    return "done"
slow()                                     # -> 'done'

@contextmanager                            # makes a function usable with `with`
def opened(name):
    print("setup")
    yield name                             # the body of the `with` runs here
    print("cleanup")                       # runs afterwards, even after an error
with opened("db") as conn:
    pass

pytest quick reference

import pytest

def test_add():
    assert 1 + 1 == 2                      # a failing assert = a failing test

def test_error():
    with pytest.raises(ValueError):        # passes only if ValueError is raised
        int("abc")

@pytest.mark.parametrize("n, expected", [(1, 2), (2, 4)])   # one test, many inputs
def test_double(n, expected):
    assert n * 2 == expected

@pytest.fixture                            # shared setup; a test asks for it by name
def user():
    return {"name": "Sree"}

def test_user(user):
    assert user["name"] == "Sree"

# Terminal:  pytest -v  (verbose)   -x  (stop at first failure)   -k name  (match test names)

Idioms & gotchas

a, b = 1, 2
a, b = b, a                    # swap two variables without a temp
a                              # -> 2
y = ""
x = y or "default"             # `or` picks the first truthy value
x                              # -> 'default'
items = []
if not items:                  # empty list / str / dict / 0 / None are all falsy
    msg = "empty"
msg                            # -> 'empty'
value = None
value is None                  # compare to None with `is`, not == -> True
parts = ["a", "b", "c"]
"".join(parts)                 # build text with join, not += in a loop -> 'abc'
print(*parts, sep=", ")        # `*` unpacks a list into arguments -> a, b, c
for i, p in enumerate(parts, start=1):   # prefer this over range(len(parts))
    pass

a = [1, 2]
b = a                          # b is another NAME for the SAME list, not a copy
b.append(3)
a                              # a changed too! -> [1, 2, 3]
c = a.copy()                   # a real (shallow) copy
c.append(4)
a                              # unchanged -> [1, 2, 3]
